# 3600 Wiring

The app for a **Thomas / International 3600** with a **Navistar T444E 7.3**. Official CTS-5123V names. Hydraulic brakes.

This is an **app**, same idea as Project Cost Tracker — not a website.

## Install

**[Open the app](https://thelubemaster.github.io/thomasvista3600/?install=1)**

| Phone | How |
| --- | --- |
| **Android** | Download the app → Install → open **3600 Wiring** |
| **iPhone** | Safari → Share → Add to Home Screen |

Direct package: [3600-wiring.apk](https://thelubemaster.github.io/thomasvista3600/3600-wiring.apk)

Once it’s on the home screen, updates check themselves when you open it.

## What’s in the app

Fuse panel, circuits (engine-critical vs not), relay pinouts, firewall cavities, hop paths, job keep/cut marks.

Job marks stay on the phone.
