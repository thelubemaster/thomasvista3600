# Wire gauge reference (CTS-5123V / T444E)

Every hop in the companion app shows **circuit ID · AWG · color · power type**.

| Circuit / use | Typical AWG | Color (book) |
|---------------|-------------|--------------|
| Battery main cables | 4/0 | RD |
| Engine/frame ground | 2/0 | BK / WH |
| Key feed 15, body builder stud | 10 | RD |
| Fuel heater load 19D | 10 | GY |
| Hyd pump motor 90H | 10 | GY |
| Glow plug feed | 8–10 | RD |
| Start relay battery 17B | 10 | RD |
| IGN bus / key outs | 12 | — |
| Allison 92D (B1) | 14 | GY |
| Horn 85 | 14 | — |
| Starter control 17C/17F | 16 | PK |
| CEC power/grounds 97 / 11-G* | 18 | VT / WH |
| Fuel filter signals 19A/B/C/J | 18 | GY |
| APS 99 / 97U | 18 | — |
| Module power 97CT/97CR | 18 | VT |

Book convention: ground circuits are **white**. Wire labels often look like `19D 10GY` (circuit + gauge + color).
